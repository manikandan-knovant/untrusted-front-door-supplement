# Untrusted at the Front Door: study materials

This repository holds the supporting materials for the article
**"Untrusted at the Front Door: A Threat Catalog for AI Agents in Health-Plan Workflows"**
by Manikandan Elumalai (Independent Researcher, ORCID [0009-0009-0049-6695](https://orcid.org/0009-0009-0049-6695)).

The article catalogs the ways an AI agent in a health-plan workflow (claims, prior
authorization, eligibility, member service, clinical documentation) can be misled by text that
arrives from outside: a fax, an X12 transaction, a C-CDA attachment, a FHIR resource. Six small
studies (A to F) test whether current models act on an instruction planted in such a packet.

All studies use **synthetic data only**. Every member, clinic, ID and claim was generated by
seeded scripts. No real patient, member, provider or customer data was used.

This work was done independently and is not affiliated with any employer.

## What is withheld, and why

The studies plant an instruction sentence in otherwise ordinary packets. Publishing those
sentences, or the packets and model responses that contain them, would publish working attack
text. So the following are **not** included:

- the planted sentences (`demo/private/payloads*.json`);
- the generated packets (`demo/private/cases*/`);
- the raw model responses (`demo/private/raw*/`), which may quote the planted sentences.

Eight documents in `demo/` are published as redacted copies: `DESIGN.md`, `PREREG_B.md` to
`PREREG_F.md`, `TEST_STRATEGY_REVIEW.md` and `reasoning_demo.md`. Each quotation of a planted
sentence is replaced by `[PLANTED SENTENCE WITHHELD - see REDACTIONS.md, item N]`. Wording from
the description notes stored with the planted sentences, which is partly made of
planted-sentence fragments, is replaced by
`[PAYLOAD NOTE WORDING WITHHELD - see REDACTIONS.md, item N]`. One local file path that held the
author's user name is replaced by `[local path removed]`. No other character is changed.
[`demo/REDACTIONS.md`](demo/REDACTIONS.md) lists every redaction (file, line, and the study and
condition it belongs to) without the redacted text. The unredacted originals are kept privately
by the author and can be verified against the SHA-256 hashes in
[`demo/ORIGINAL_HASHES.txt`](demo/ORIGINAL_HASHES.txt) (for example with `sha256sum -c`).

Also not included: the article drafts, the literature notes and full texts (copyrighted), and
the catalog checker `check_catalog.py`, which depends on those literature notes.

Because of this, `gen_cases*.py` and `harness*.py` are included so readers can see how the
studies were built and run, but they cannot be run as is: they read the withheld planted
sentences and packets. `figures/make_fig1.py` imports `check_catalog.py`, which is not included,
so the figure files are provided ready-made.

## How to rerun the summaries

You need Python 3 (standard library only). No API key and no network access are needed.

```
cd demo
python summarize.py A
python summarize.py B
python summarize.py C
python summarize.py D
python summarize.py E
python summarize.py F
```

Each command reads that study's `runs.jsonl`, prints the tables, and rewrites `table.md` and
`run_meta.json` in the same folder. If you cloned this repository with git, `git status` should
then show no changes: the rebuilt files match the committed ones byte for byte.

Row counts: A 1,000; B 600; C 600; D 3,200; E 800; F 1,600; 7,800 in total.

|---|---|---|---|---|

| D, E, F | `claude-sonnet-5-5`, `gpt-6.2-sol`, `claude-haiku-5-5`, `gpt-6-luna` | 1.0 (provider default, sent explicitly) | medium | 8,192 |

Run order was shuffled with seed 4417 so that control and test runs interleave in time.
The agent's tools were mocks: no real claim, payer or records system was contacted.

## API keys

API keys are read from environment variables (on Windows, also the user environment in the
registry); nothing is printed or stored. This happens at call time in `get_key()` in
`demo/providers.py`. No key is included in this repository.
